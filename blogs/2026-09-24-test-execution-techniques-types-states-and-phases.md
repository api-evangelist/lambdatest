Test execution techniques are the strategies that shape how test cases are prioritized, staged, and run against software under test, spanning manual, automated, exploratory, and AI-powered approaches. Rather than changing how tests themselves execute, these techniques organize execution into states, priorities such as risk-based, coverage-based, history-based, and requirement-based, and phases.
